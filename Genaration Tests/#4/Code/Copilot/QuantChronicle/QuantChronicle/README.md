# QuantChronicle

Full-stack financial analytics platform built with FastAPI, PostgreSQL, SQLAlchemy, Pandas, NumPy, Scikit-Learn and Matplotlib.

Features:
- JWT authentication
- Transaction and event management
- UTC timestamp storage with timezone conversion
- Spending analytics
- Forecasting and anomaly detection
- Background analytics jobs
- Simulation mode
- REST APIs
- Dark-themed dashboard placeholder

Run:
uvicorn app.main:app --reload
